## 前言

MongoDB 是一个流行的 NoSQL 数据库，以其灵活的文档模型和高性能著称。本文介绍如何在 macOS 上安装和配置 MongoDB 7.x/8.x。

## 系统要求

- macOS 12+ (Monterey) 或更高版本
- Homebrew 已安装

## 使用 Homebrew 安装（推荐）

```bash
# 添加 MongoDB tap
brew tap mongodb/brew

# 安装 MongoDB Community Edition
brew install mongodb-community

# 启动 MongoDB 服务
brew services start mongodb-community
```

安装完成后，MongoDB 会自动配置：
- 数据目录：`/usr/local/var/mongodb`
- 配置文件：`/usr/local/etc/mongod.conf`
- 日志文件：`/usr/local/var/log/mongodb/mongod.log`

## 连接数据库

```bash
# 使用 mongosh 连接（MongoDB 6.0+ 推荐）
mongosh

# 连接指定数据库
mongosh mydatabase
```

## 常用命令

```javascript
// 查看所有数据库
show dbs

// 切换数据库
use mydatabase

// 查看当前数据库中的集合
show collections

// 插入文档
db.users.insertOne({ name: 'John', age: 25 })

// 查询文档
db.users.find({ age: { $gte: 18 } })

// 更新文档
db.users.updateOne({ name: 'John' }, { $set: { age: 26 } })

// 删除文档
db.users.deleteOne({ name: 'John' })
```

## 配置 MongoDB

### 查看默认配置

Homebrew 安装的 MongoDB 已有默认配置文件：

```bash
cat /usr/local/etc/mongod.conf
```

### 常用配置项

```yaml
# 网络配置
net:
  port: 27017
  bindIp: 127.0.0.1

# 存储配置
storage:
  dbPath: /usr/local/var/mongodb
  journal:
    enabled: true

# 日志配置
systemLog:
  destination: file
  path: /usr/local/var/log/mongodb/mongod.log
  logAppend: true
```

### 自定义配置

如需修改配置，编辑配置文件后重启服务：

```bash
# 编辑配置
vim /usr/local/etc/mongod.conf

# 重启 MongoDB
brew services restart mongodb-community
```

## 常用操作

### 查看服务状态

```bash
brew services list | grep mongodb
```

### 停止服务

```bash
brew services stop mongodb-community
```

### 卸载 MongoDB

```bash
brew services stop mongodb-community
brew uninstall mongodb-community
brew untap mongodb/brew
```

## 总结

MongoDB 是一个功能强大的 NoSQL 数据库，适合存储灵活的文档数据。通过 Homebrew 安装是最简单的方式，建议使用 `mongosh` 连接数据库。
