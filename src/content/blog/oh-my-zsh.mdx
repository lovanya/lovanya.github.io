## 一、平台安装指南

### macOS 安装

#### 1. 检查 Zsh

macOS Catalina（2019）及以上已默认使用 Zsh：

```bash
zsh --version
```

**预期输出**：
```
zsh 5.9 (x86_64-apple-darwin22.0)
```

#### 2. 安装 Oh My Zsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

**安装过程说明**：
- 自动备份 `~/.zshrc` 为 `~/.zshrc.pre-oh-my-zsh`
- 创建新的 `~/.zshrc` 配置文件
- 切换默认 shell 为 zsh
- 安装完成后会显示 ASCII 艺术图案

#### 3. 验证安装

```bash
# 检查 Oh My Zsh 版本
omz version

# 查看 Oh My Zsh 安装路径
echo $ZSH

# 预期输出：/Users/你的用户名/.oh-my-zsh
```

#### 4. 卸载

```bash
uninstall_oh_my_zsh
```

### Windows 安装

Windows 上安装 Oh My Zsh 需要先安装 WSL（Windows Subsystem for Linux），因为 Oh My Zsh 基于 Zsh，不支持原生 Windows。

#### 1. 安装 WSL

以管理员身份打开 PowerShell：

```powershell
wsl --install
```

**说明**：
- 默认安装 Ubuntu 发行版
- 安装过程中会提示设置用户名和密码
- 安装完成后需要重启

重启后，Ubuntu 会自动启动并完成初始化。

#### 2. 更新系统

```bash
sudo apt update && sudo apt upgrade -y
```

#### 3. 安装 Zsh

```bash
sudo apt install zsh -y
```

**验证**：
```bash
zsh --version
```

#### 4. 安装 Oh My Zsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

#### 5. 设置 Zsh 为默认 Shell

```bash
chsh -s $(which zsh)
```

**重新登录 WSL** 后生效，或重启终端。

#### 6. 在 Windows 终端中配置

编辑 WSL 配置 `~/.zshrc`：

```bash
# 启动 Oh My Zsh
source $ZSH/oh-my-zsh.sh
```

**推荐：在 Windows 终端中使用 WSL**

打开 Windows 终端 → 设置 → 添加新配置文件：

- **名称**：Ubuntu
- **命令行**：`wsl.exe -d Ubuntu`
- **启动目录**：`~`

#### 7. 卸载

```bash
uninstall_oh_my_zsh
```

#### 常见问题

**Q: curl 命令找不到？**
```bash
sudo apt install curl -y
```

**Q: git 命令找不到？**
```bash
sudo apt install git -y
```

**Q: WSL 字体显示异常？**

安装 Nerd Font 后，在 Windows 终端设置中选择 Nerd Font。

## 二、主题选择

### 内置主题

编辑 `~/.zshrc`：

```bash
ZSH_THEME="robbyrussell"  # 默认，简洁
```

### 推荐的第三方主题

#### 1. Powerlevel10k（推荐）

最快的 Zsh 主题，启动速度比 Powerlevel9k 快 10 倍：

```bash
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k
```

设置 `~/.zshrc`：

```bash
ZSH_THEME="powerlevel10k/powerlevel10k"
```

安装后运行配置向导：

```bash
p10k configure
```

**配置选项**：
- Rainbow / Lean / Classic / Pure 风格
- Unicode / ASCII 字符
- 显示 Git 状态、Node 版本、时间等

#### 2. Spaceship

显示 Git、Node、Docker 等信息：

```bash
git clone https://github.com/spaceship-prompt/spaceship-prompt.git \
  "$ZSH_CUSTOM/themes/spaceship-prompt" --depth=1

ln -s "$ZSH_CUSTOM/themes/spaceship-prompt/spaceship.zsh-theme" \
  "$ZSH_CUSTOM/themes/spaceship.zsh-theme"
```

```bash
ZSH_THEME="spaceship"
```

> **想要更轻量、跨平台的终端提示符？** 试试 [Starship](https://lovanya.com/blog/starship-prompt/)：用 Rust 编写，毫秒级启动，配置即代码。

## 三、核心插件

### 必装插件

#### 1. zsh-autosuggestions

根据历史命令自动建议：

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

**使用技巧**：
- `→` 键接受建议
- `Ctrl + →` 接受部分建议

#### 2. zsh-syntax-highlighting

命令语法高亮（正确命令绿色，错误红色）：

```bash
git clone https://github.com/zsh-users/zsh-syntax-highlighting \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

#### 3. zsh-completions

额外的自动补全规则：

```bash
git clone https://github.com/zsh-users/zsh-completions \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-completions
```

### 效率插件

#### 4. z（快速跳转目录）

Oh My Zsh 内置，基于历史记录快速跳转：

```bash
plugins=(z)

z project      # 跳转到包含 "project" 的目录
z src          # 跳转到 src 目录
```

#### 5. extract（万能解压）

一个命令解压所有格式：

```bash
plugins=(extract)

extract archive.tar.gz
extract file.zip
extract image.rar
```

#### 6. git-extras

Git 增强命令：

```bash
brew install git-extras
```

常用命令：
```bash
git summary     # 仓库摘要
git effort      # 文件贡献统计
git changelog   # 生成 changelog
git release     # 创建 release
```

### 开发插件

#### 7. Docker 插件

```bash
plugins=(docker docker-compose)
```

补全：
- `docker ps` → `dps`
- `docker images` → `dim`
- `docker-compose` → `dc`

#### 8. Node.js 插件

```bash
plugins=(node npm)
```

别名：
- `ni` = `npm install`
- `nid` = `npm install --save-dev`
- `np` = `npm publish`
- `nt` = `npm test`

#### 9. Git 插件（增强）

```bash
plugins=(git gitignore git-flow)
```

常用别名：

| 别名 | 命令 | 说明 |
|------|------|------|
| `gst` | `git status` | 状态 |
| `ga` | `git add` | 添加 |
| `gaa` | `git add --all` | 全部添加 |
| `gc` | `git commit -v` | 提交 |
| `gcmsg` | `git commit -m` | 提交消息 |
| `gp` | `git push` | 推送 |
| `gl` | `git pull` | 拉取 |
| `gd` | `git diff` | 差异 |
| `gco` | `git checkout` | 切换 |
| `gb` | `git branch` | 分支 |
| `glog` | `git log --oneline --graph` | 日志图 |

## 四、推荐配置

### 完整 ~/.zshrc 配置

```bash
# Path
export ZSH="$HOME/.oh-my-zsh"

# 主题
ZSH_THEME="powerlevel10k/powerlevel10k"

# 插件
plugins=(
  git
  z
  extract
  zsh-autosuggestions
  zsh-syntax-highlighting
  zsh-completions
  docker
  node
  npm
)

# 补全缓存
fpath+=${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-completions/src

source $ZSH/oh-my-zsh.sh

# 用户配置
bindkey -e  # Emacs 键绑定

# 历史记录配置
HISTSIZE=10000
SAVEHIST=10000
HISTFILE=~/.zsh_history
setopt HIST_IGNORE_DUPS
setopt HIST_IGNORE_SPACE
setopt SHARE_HISTORY

# 自动补全配置
autoload -Uz compinit && compinit
zstyle ':completion:*' matcher-list 'm:{a-z}={A-Za-z}'
```

### 性能优化

#### 延迟加载（加速启动）

```bash
# 懒加载 nvm（Node 版本管理）
export NVM_LAZY_LOAD=true

# 懒加载命令补全
lazy_load_cmd() {
  unset -f npm node npx 2>/dev/null
  export PATH="$HOME/.nvm/versions/node/$(nvm version default)/bin:$PATH"
}

# 延迟加载 git-extras
lazy_load_git_extras() {
  unset -f git-summary git-effort 2>/dev/null
  eval "$(git-extras --init)"
}
```

#### 缓存补全

```bash
# 检查补全缓存是否存在
autoload -Uz compinit
if [[ -n ${ZDOTDIR:-$HOME}/.zcompdump(#qN.mh+24) ]]; then
  compinit -C
else
  compinit
fi
```

### 函数配置

```bash
# 创建项目目录并进入
mkcd() {
  mkdir -p "$1" && cd "$1"
}

# 快速创建 Git 仓库
gitnew() {
  mkdir -p "$1" && cd "$1"
  git init
  echo "# $1" > README.md
  git add .
  git commit -m "Initial commit"
}

# 查看端口占用
port() {
  lsof -i :$1
}

# 快速备份文件
backup() {
  cp "$1" "$1.backup.$(date +%Y%m%d%H%M%S)"
}
```

## 六、常见问题

### 启动速度慢

```bash
# 测量启动时间
time zsh -i -c exit

# 诊断慢插件
zprof  # 在 ~/.zshrc 开头添加 zmodload zsh/zprof
```

**优化方案**：
1. 减少插件数量（只保留必装的 5-6 个）
2. 使用 Powerlevel10k（内置即时提示）
3. 启用延迟加载
4. 缓存补全系统

### 主题显示异常

```bash
# 安装 Nerd Font（Powerlevel10k 需要）
brew install --cask font-fira-code-nerd-font

# 在终端设置中选择 Nerd Font
```

Windows 用户：
```bash
# 在 WSL 中下载字体配置
sudo apt install fontconfig
```

或在 Windows 端安装 Nerd Font 后，在 Windows 终端设置中配置。

### 插件不生效

```bash
# 重新生成补全缓存
rm -f ~/.zcompdump*
compinit

# 重新加载配置
source ~/.zshrc
```

## 总结

Oh My Zsh 的核心价值在于**插件生态**和**社区支持**。配置建议：

1. **主题选 Powerlevel10k**：性能最好，配置最灵活
2. **必装 5 个插件**：autosuggestions、syntax-highlighting、completions、z、extract
3. **按需添加开发插件**：docker、node、git
4. **定期清理**：删除不用的插件和主题
5. **备份配置**：将 `~/.zshrc` 纳入 dotfiles 管理
