## 前言

Oh My Zsh 是一个管理 Zsh 配置的开源框架，提供了大量的主题和插件，让你的终端变得更高效、更美观。

## 检查 Zsh

macOS Catalina（2019 年 10 月）及以上版本已默认使用 Zsh。检查当前版本：

```bash
zsh --version
```

如果需要安装或更新 Zsh：

```bash
brew install zsh
```

## 安装 Oh My Zsh

使用官方安装脚本：

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

安装完成后，你会看到一个漂亮的 ASCII 艺术图案。

## 配置主题

编辑 `~/.zshrc` 文件，找到 `ZSH_THEME` 配置项：

```bash
ZSH_THEME="robbyrussell"
```

推荐几个常用主题：
- `robbyrussell` - 默认主题，简洁
- `agnoster` - 功能丰富，需要 Powerline 字体
- `spaceship` - 显示 Git 信息和 Node 版本（需单独安装）

### 安装 spaceship 主题

```bash
git clone https://github.com/denysdovhan/spaceship-prompt.git "$ZSH_CUSTOM/themes/spaceship-prompt"

# 创建符号链接
ln -s "$ZSH_CUSTOM/themes/spaceship-prompt/spaceship.zsh-theme" "$ZSH_CUSTOM/themes/spaceship.zsh-theme"
```

在 `~/.zshrc` 中设置：

```bash
ZSH_THEME="spaceship"
```

## 推荐插件

### git 插件

Oh My Zsh 自带 git 插件，提供了很多 git 命令的别名：

```bash
plugins=(git)
```

常用别名：
- `gst` = `git status`
- `ga` = `git add`
- `gc` = `git commit`
- `gp` = `git push`
- `gl` = `git pull`

### zsh-autosuggestions 插件

自动建议你之前输入过的命令：

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

在 `~/.zshrc` 中添加：

```bash
plugins=(git zsh-autosuggestions)
```

### zsh-syntax-highlighting 插件

提供命令语法高亮功能：

```bash
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

## 总结

Oh My Zsh 是一个非常强大的终端增强工具，通过合理的配置可以大大提高开发效率。建议根据自己的需求选择合适的主题和插件。
