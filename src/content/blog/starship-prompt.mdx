## 前言

Starship 是一个用 Rust 编写的跨平台终端提示符，**毫秒级启动**、**配置即代码**、**开箱即用**。相比 Oh My Zsh 的主题，Starship 启动速度快 10 倍以上，且跨平台表现一致。

本文从安装到深度定制，完整覆盖 Starship 的使用。

## 一、为什么选择 Starship

### 核心优势

| 特性 | Starship | Oh My Zsh | Powerlevel10k |
|------|----------|-----------|---------------|
| 启动速度 | < 10ms | 100-500ms | 50-100ms |
| 跨平台 | 全部支持 | macOS/Linux | macOS/Linux |
| 配置文件 | `starship.toml` | `~/.zshrc` | `~/.p10k.zsh` |
| 预置模块 | 500+ | 300+ 插件 | 内置 |
| 学习曲线 | 低 | 中 | 中 |

### 适用场景

- **追求极致性能**：不喜欢主题拖慢终端
- **多平台统一**：macOS、Linux、Windows 同样的体验
- **配置即代码**：`starship.toml` 可以纳入 dotfiles 仓库
- **不想折腾**：开箱即用，自动检测环境

## 二、平台安装

### 前置条件

- **macOS**：10.13+
- **Linux**：任何现代发行版
- **Windows**：Windows 10 1809+ 或 Windows 11

支持的 Shell：
- Bash 4.4+
- Zsh 5.0+
- Fish 3.1+
- PowerShell 5.1+
- Ion 1.0+
- Elvish 0.18+
- Tcsh 6.20+
- Nushell 0.78+
- Xonsh
- Cmd

### macOS 安装

#### 1. 使用 Homebrew（推荐）

```bash
brew install starship
```

#### 2. 初始化到 Shell 配置文件

**Zsh**（`~/.zshrc`）：
```bash
eval "$(starship init zsh)"
```

**Bash**（`~/.bashrc`）：
```bash
eval "$(starship init bash)"
```

**Fish**（`~/.config/fish/config.fish`）：
```fish
starship init fish | source
```

#### 3. 验证

重启终端，运行：

```bash
starship --version
```

**预期输出**：`starship 1.x.x`

#### 4. 卸载

```bash
brew uninstall starship
```

并从 shell 配置文件中删除 `eval "$(starship init zsh)"` 行。

### Windows 安装

#### 方法一：Scoop（推荐）

```powershell
scoop install starship
```

#### 方法二：winget

```powershell
winget install --id Starship.Starship
```

#### 方法三：手动安装

从 [GitHub Releases](https://github.com/starship/starship/releases) 下载 `starship-x86_64-pc-windows-msvc.zip`，解压到 `C:\Program Files\starship\`。

#### 初始化到 PowerShell

创建或编辑 `$PROFILE`（`Microsoft.PowerShell_profile.ps1`）：

```powershell
Invoke-Expression (&starship init powershell)
```

#### 验证

```powershell
starship --version
```

### Linux 安装

#### 1. 使用官方脚本

```bash
curl -sS https://starship.rs/install.sh | sh
```

**说明**：脚本会自动：
- 检测系统架构
- 下载最新版本
- 安装到 `~/.local/bin/`
- 提示添加到 PATH

#### 2. 确保 `~/.local/bin` 在 PATH 中

**Bash**（`~/.bashrc`）：
```bash
export PATH="$HOME/.local/bin:$PATH"
```

**Zsh**（`~/.zshrc`）：
```bash
export PATH="$HOME/.local/bin:$PATH"
```

**Fish**：
```fish
set -gx PATH $HOME/.local/bin $PATH
```

#### 3. 初始化

```bash
eval "$(starship init zsh)"  # 或 bash、fish
```

#### 4. 验证

```bash
starship --version
```

### 初始化 Nushell

```nushell
mkdir ~/.cache/starship
starship init nu | save -f ~/.cache/starship/init.nu
```

在 `~/.config/nushell/config.nu` 中添加：

```nushell
source ~/.cache/starship/init.nu
```

## 三、字体配置

### Nerd Font（推荐）

Starship 使用 Nerd Font 中的图标来增强显示效果。

#### 安装 Nerd Font

**macOS**：
```bash
brew tap homebrew/cask-fonts
brew install --cask font-fira-code-nerd-font
brew install --cask font-jetbrains-mono-nerd-font
```

**Windows**：从 [Nerd Fonts Releases](https://github.com/ryanoasis/nerd-fonts/releases) 下载并安装。

**Linux**（Ubuntu/Debian）：
```bash
mkdir -p ~/.local/share/fonts
cd ~/.local/share/fonts
curl -fLO https://github.com/ryanoasis/nerd-fonts/releases/latest/download/FiraCode.zip
unzip FiraCode.zip
fc-cache -fv
```

#### 配置终端使用 Nerd Font

- **iTerm2**：Preferences → Profiles → Text → Font
- **Windows Terminal**：Settings → Profiles → Appearance → Font face
- **GNOME Terminal**：Profile → Preferences → Custom font
- **Alacritty**：`~/.config/alacritty/alacritty.toml`：
  ```toml
  [font]
  normal = { family = "FiraCode Nerd Font", style = "Regular" }
  ```

## 四、配置文件

### 配置文件位置

- **macOS/Linux**：`~/.config/starship.toml`
- **Windows**：`%USERPROFILE%\.config\starship.toml`

### 创建配置文件

```bash
mkdir -p ~/.config
touch ~/.config/starship.toml
```

### 最小配置

```toml
# starship.toml

# 禁用换行符前的提示符
add_newline = false

# 提示符字符
[character]
success_symbol = "[➜](bold green)"
error_symbol = "[➜](bold red)"
```

### 预设配置

Starship 提供了多个 [官方预设](https://starship.rs/presets/)：

```bash
# 预览所有预设
starship preset

# 应用预设
starship preset tokyo-night > ~/.config/starship.toml

# 列出可用预设
starship preset --list
```

常用预设：
- `tokyo-night` - 东京夜色风格
- `gruvbox-rainbow` - Gruvbox 彩虹色
- `pastel-powerline` - 柔和 Powerline
- `pure-preset` - 极简风格

## 五、模块配置

### 启用的模块（默认）

Starship 默认启用以下模块：
- `directory`
- `git_branch`
- `git_status`
- `nodejs`
- `python`
- `rust`
- `package`

### 基础配置示例

```toml
# 目录模块
[directory]
style = "bold cyan"
truncation_length = 3
truncation_symbol = "…/"

[directory.substitutions]
"Documents" = "📂 "
"Downloads" = "📥 "
"Developer" = "💻 "

# Git 模块
[git_branch]
symbol = "🌱 "
truncation_length = 4
truncation_symbol = "…"

[git_status]
ahead = "⇡${count}"
diverged = "⇕⇡${ahead_count}⇣${behind_count}"
behind = "⇣${count}"
conflicted = "🏳️"

# Node.js 模块
[nodejs]
symbol = "⬢ "
style = "bold green"
version_format = "v${raw}"

# Python 模块
[python]
symbol = "🐍 "
style = "bold yellow"

# Rust 模块
[rust]
symbol = "🦀 "
style = "bold red"

# Docker 模块
[docker_context]
symbol = "🐳 "
```

### 自定义命令模块

显示自定义命令的输出：

```toml
[custom.example]
command = "echo example"
style = "bold yellow"
when = "true"
format = "[$symbol$output]($style)"
```

### 条件显示

根据当前目录或文件显示：

```toml
[docker_context]
only_with_files = true  # 仅在有 Dockerfile 时显示

[package]
disabled = false
```

### 时间模块

```toml
[time]
disabled = false
format = "🕙[ $time ]($style)"
time_format = "%R"
style = "bold yellow"
```

## 六、常用模块详解

### 1. directory（目录）

```toml
[directory]
style = "bold cyan"
truncation_length = 3
truncation_symbol = "…/"
truncation_strategy = "in_middle"
read_only = " 🔒"
read_only_style = "bold red"
home_symbol = "🏠 "
```

### 2. git_branch / git_status

```toml
[git_branch]
symbol = "🌿 "
style = "bold purple"
truncation_length = 4
ignore_branches = ["master", "main"]

[git_status]
style = "bold red"
ahead = "⇡"
behind = "⇣"
diverged = "⇕"
conflicted = "🏳️"
untracked = "?️"
stashed = "📦"
modified = "!"
staged = "+"
renamed = "»"
deleted = "✘"
```

### 3. character（提示符字符）

```toml
[character]
success_symbol = "[➜](bold green)"
error_symbol = "[➜](bold red)"
vicmd_symbol = "[❮](bold green)"
```

### 4. 命令执行时间

```toml
[cmd_duration]
min_time = 2_000  # 超过 2 秒才显示
format = "took [$duration]($style)"
style = "bold yellow"
```

### 5. 内存使用

```toml
[memory_usage]
symbol = "🐏 "
style = "bold dimmed white"
threshold = 75  # 使用超过 75% 时显示
format = "via $symbol[$ram_pct]($style) "
```

## 七、性能优化

### 异步模块（减少阻塞）

Starship 默认异步检测模块状态，但有些模块可能阻塞。检查慢模块：

```bash
starship timings
```

**示例输出**：
```
━━━ timings ━━━
directory: 0.5ms
git_branch: 0.3ms
git_status: 12.4ms  ← 较慢
nodejs: 8.2ms
```

优化方案：
1. 禁用不常用的模块
2. 使用 `detect_files` 减少自动检测
3. 升级 Starship 到最新版

### 减少模块数量

```toml
# 禁用不需要的模块
[package]
disabled = true

[python]
disabled = true

[rust]
disabled = true
```

### 使用预设的精简版本

```bash
# 应用最小化预设
starship preset pure-preset > ~/.config/starship.toml
```

在 `~/.config/Code/User/settings.json` 中：

{
  "terminal.integrated.fontFamily": "FiraCode Nerd Font",
  "terminal.integrated.shell.osx": "/bin/zsh"

Settings → Tools → Terminal → Shell path: `/bin/zsh`

### Vim/Neovim

使用 [vim-starhip](https://github.com/mhinz/vim-starhip) 或自定义 statusline。

## 九、常见问题

### 1. 提示符显示乱码

**原因**：未安装 Nerd Font。

**解决**：参考上面的字体配置章节。

### 2. 启动慢

**诊断**：
```bash
starship timings
```

**优化**：
- 禁用不需要的模块
- 升级到最新版 Starship
- 异步模块生效

### 3. 模块不显示

**检查**：
```bash
# 查看配置语法
starship explain

# 测试配置
starship print
```

### 4. 颜色不正确

确保终端支持 256 色或真彩色（true color）：

```bash
echo $COLORTERM
# 期望输出：truecolor 或 256color
```

**iTerm2**：Preferences → Profiles → Terminal → Report terminal type: `xterm-256color`

**Windows Terminal**：默认支持真彩色。

## 十、最佳实践

### 1. 配置纳入 dotfiles

```bash
# ~/.dotfiles/starship/starship.toml
# 在 .zshrc 中：
export STARSHIP_CONFIG=~/.dotfiles/starship/starship.toml
eval "$(starship init zsh)"
```

### 2. 项目级配置

为不同项目使用不同配置：

```bash
# 在项目根目录的 .starship.toml 中
[directory]
truncation_length = 5
```

Starship 会自动从当前目录向上查找 `.starship.toml`。

### 3. 主题化

使用 [starship-theme](https://github.com/topics/starship-theme) 主题：

```bash
# 克隆主题
git clone https://github.com/your-theme/starship-theme.git

# 复制配置
cp starship-theme/starship.toml ~/.config/starship.toml
```

### 4. 与 tmux 配合

在 `~/.tmux.conf` 中：

```tmux
set -g default-terminal "tmux-256color"
set -ga terminal-overrides ',xterm-256color:Tc'
```

## 总结

Starship 的核心优势：

1. **极速启动**：< 10ms，几乎无感知
2. **跨平台一致**：macOS、Linux、Windows 同样的体验
3. **配置即代码**：`starship.toml` 易于维护和分享
4. **模块化设计**：按需启用，可深度定制

如果你追求**极致性能**和**统一体验**，Starship 是当前最好的选择。
