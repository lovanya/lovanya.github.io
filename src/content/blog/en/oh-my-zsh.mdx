## Introduction

Oh My Zsh is an open-source Zsh configuration management framework with 300+ plugins and 150+ themes. But most tutorials only cover "installation" — this guide focuses on building a **truly productive terminal environment** from a developer efficiency perspective.

## 1. Installation

### Prerequisites

macOS Catalina (October 2019) and later use Zsh by default:

```bash
zsh --version  # 5.9+ recommended
```

### Install Oh My Zsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

The install script automatically:
- Backs up existing `~/.zshrc` to `~/.zshrc.pre-oh-my-zsh`
- Creates a new `~/.zshrc` configuration
- Switches default shell to zsh

### Uninstall

```bash
uninstall_oh_my_zsh
```

## 2. Theme Selection

### Built-in Themes

Edit `~/.zshrc`:

```bash
ZSH_THEME="robbyrussell"  # Default, minimal
```

### Recommended Third-party Themes

#### Powerlevel10k (Recommended)

The fastest Zsh theme, 10x faster than Powerlevel9k:

```bash
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git \
  ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k
```

Set in `~/.zshrc`:

```bash
ZSH_THEME="powerlevel10k/powerlevel10k"
```

Run the configuration wizard:

```bash
p10k configure
```

**Options**: Rainbow / Lean / Classic / Pure styles, Unicode / ASCII characters, Git status, Node version, time display, etc.

#### Spaceship

Shows Git, Node, Docker information:

```bash
git clone https://github.com/spaceship-prompt/spaceship-prompt.git \
  "$ZSH_CUSTOM/themes/spaceship-prompt" --depth=1

ln -s "$ZSH_CUSTOM/themes/spaceship-prompt/spaceship.zsh-theme" \
  "$ZSH_CUSTOM/themes/spaceship.zsh-theme"
```

```bash
ZSH_THEME="spaceship"
```

#### Starship (Cross-platform)

Written in Rust, excellent performance:

```bash
brew install starship
```

Add to `~/.zshrc`:

```bash
eval "$(starship init zsh)"
```

## 3. Essential Plugins

### Must-Have Plugins

#### zsh-autosuggestions

Auto-suggests commands based on history:

```bash
git clone https://github.com/zsh-users/zsh-autosuggestions \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
```

**Tips**:
- `→` key to accept suggestion
- `Ctrl + →` to accept partial suggestion

#### zsh-syntax-highlighting

Command syntax highlighting (green for correct, red for errors):

```bash
git clone https://github.com/zsh-users/zsh-syntax-highlighting \
  ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

#### zsh-completions

Additional autocompletion rules:

```bash
git clone https://github.com/zsh-users/zsh-completions \
  ${ZSH_CUSTOM:-${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/custom}/plugins/zsh-completions
```

### Productivity Plugins

#### z (Quick Directory Jump)

Built-in, jumps to directories based on history:

```bash
plugins=(z)

z project      # Jump to directory containing "project"
z src          # Jump to src directory
```

#### extract (Universal Extractor)

One command for all archive formats:

```bash
plugins=(extract)

extract archive.tar.gz
extract file.zip
extract image.rar
```

### Development Plugins

#### Docker Plugin

```bash
plugins=(docker docker-compose)
```

Completions: `docker ps` → `dps`, `docker images` → `dim`, `docker-compose` → `dc`

#### Node.js Plugin

```bash
plugins=(node npm)
```

Aliases: `ni` = `npm install`, `nid` = `npm install --save-dev`, `np` = `npm publish`, `nt` = `npm test`

#### Git Plugin (Enhanced)

```bash
plugins=(git gitignore git-flow)
```

Common aliases:

| `gst` | `git status` | Status |
| `ga` | `git add` | Add |
| `gaa` | `git add --all` | Add all |
| `gc` | `git commit -v` | Commit |
| `gcmsg` | `git commit -m` | Commit message |
| `gp` | `git push` | Push |
| `gl` | `git pull` | Pull |

| `gb` | `git branch` | Branch |
| `glog` | `git log --oneline --graph` | Log graph |

## 4. Recommended Configuration

### Complete ~/.zshrc

```bash
export ZSH="$HOME/.oh-my-zsh"

ZSH_THEME="powerlevel10k/powerlevel10k"

plugins=(
  git
  z
  extract
  zsh-autosuggestions
  zsh-syntax-highlighting
  zsh-completions
  docker
  node
  npm
)

fpath+=${ZSH_CUSTOM:-${ZSH:-~/.oh-my-zsh}/custom}/plugins/zsh-completions/src

source $ZSH/oh-my-zsh.sh

bindkey -e  # Emacs key bindings

HISTSIZE=10000
SAVEHIST=10000
HISTFILE=~/.zsh_history
setopt HIST_IGNORE_DUPS
setopt HIST_IGNORE_SPACE
setopt SHARE_HISTORY

autoload -Uz compinit && compinit
zstyle ':completion:*' matcher-list 'm:{a-z}={A-Za-z}'
```

### Performance Optimization

#### Lazy Loading (Faster Startup)

```bash
export NVM_LAZY_LOAD=true
```

#### Completion Caching

```bash
autoload -Uz compinit
if [[ -n ${ZDOTDIR:-$HOME}/.zcompdump(#qN.mh+24) ]]; then
  compinit -C
else
  compinit
fi
```

## 6. Troubleshooting

### Slow Startup

```bash
# Measure startup time
time zsh -i -c exit

# Diagnose slow plugins
zprof
```

**Solutions**:
1. Reduce plugins (keep only 5-6 essential ones)
2. Use Powerlevel10k (built-in instant prompt)
3. Enable lazy loading
4. Cache completions

### Theme Display Issues

```bash
# Install Nerd Font (required for Powerlevel10k)
brew install --cask font-fira-code-nerd-font

# Select Nerd Font in terminal settings
```

### Plugins Not Working

```bash
# Regenerate completion cache
rm -f ~/.zcompdump*
compinit

# Reload configuration
source ~/.zshrc
```

## Summary

Core principles for Oh My Zsh configuration:

1. **Theme: Powerlevel10k** — Best performance, most flexible
2. **5 Essential Plugins**: autosuggestions, syntax-highlighting, completions, z, extract
3. **Add Dev Plugins**: docker, node, git as needed
4. **Regular Cleanup**: Remove unused plugins and themes
5. **Backup Config**: Include `~/.zshrc` in dotfiles management
