## Introduction

MongoDB is a popular NoSQL database known for its flexible document model and high performance. This guide covers how to install and configure MongoDB 7.x/8.x on macOS.

## System Requirements

- macOS 12+ (Monterey) or later
- Homebrew installed

## Installation with Homebrew (Recommended)

```bash
# Add MongoDB tap
brew tap mongodb/brew

# Install MongoDB Community Edition
brew install mongodb-community

# Start MongoDB service
brew services start mongodb-community
```

After installation, MongoDB is automatically configured with:
- Data directory: `/usr/local/var/mongodb`
- Configuration file: `/usr/local/etc/mongod.conf`
- Log file: `/usr/local/var/log/mongodb/mongod.log`

## Connecting to the Database

```bash
# Connect using mongosh (recommended for MongoDB 6.0+)
mongosh

# Connect to a specific database
mongosh mydatabase
```

## Common Commands

```javascript
// View all databases
show dbs

// Switch database
use mydatabase

// View collections in current database
show collections

// Insert a document
db.users.insertOne({ name: 'John', age: 25 })

// Query documents
db.users.find({ age: { $gte: 18 } })

// Update a document
db.users.updateOne({ name: 'John' }, { $set: { age: 26 } })

// Delete a document
db.users.deleteOne({ name: 'John' })
```

## Configuring MongoDB

### View Default Configuration

Homebrew-installed MongoDB comes with a default configuration file:

```bash
cat /usr/local/etc/mongod.conf
```

### Common Configuration Options

```yaml
# Network configuration
net:
  port: 27017
  bindIp: 127.0.0.1

# Storage configuration
storage:
  dbPath: /usr/local/var/mongodb
  journal:
    enabled: true

# Logging configuration
systemLog:
  destination: file
  path: /usr/local/var/log/mongodb/mongod.log
  logAppend: true
```

### Custom Configuration

To modify configuration, edit the config file and restart the service:

```bash
# Edit configuration
vim /usr/local/etc/mongod.conf

# Restart MongoDB
brew services restart mongodb-community
```

## Common Operations

### Check Service Status

```bash
brew services list | grep mongodb
```

### Stop Service

```bash
brew services stop mongodb-community
```

### Uninstall MongoDB

```bash
brew services stop mongodb-community
brew uninstall mongodb-community
brew untap mongodb/brew
```

## Summary

MongoDB is a powerful NoSQL database suitable for storing flexible document data. Installation via Homebrew is the simplest method, and it's recommended to use `mongosh` for database connections.
